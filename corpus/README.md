# 语料准备 · Corpus setup

本项目**不分发**海子诗作全文。分析管线是公开、可复现的——你只需把一份本地语料放入本目录，即可生成自己的图谱。

> 海子（查海生，1964–1989）的诗作仍在版权保护期内。请仅将语料用于个人学习与研究。

## 两种方式

### 方式一：已有纯文本（最简单）

把你已有的纯文本语料命名为 `haizi.txt`，放入本目录：

```text
corpus/
├── README.md
└── haizi.txt      # UTF-8 纯文本，一首诗接一首诗
```

然后直接运行：

```bash
.venv/bin/python -m pipeline.run
```

### 方式二：从 PDF 提取

如果你手头是 PDF（例如西川编《海子诗全集》），把 PDF 放入本目录，然后：

```bash
# 提取正文（需要 pdfplumber）
.venv/bin/pip install pdfplumber
.venv/bin/python -m pipeline.extract corpus/海子诗全集.pdf --out corpus/haizi.txt

# 之后照常运行
.venv/bin/python -m pipeline.run
```

`extract` 默认跳过目录/序言等前部页面（`--start` / `--end` 可调，0 起索引，见 `--help`）。

## 目录里有什么会被提交

| 文件 | 是否提交 | 说明 |
|------|---------|------|
| `README.md` | ✅ | 本说明 |
| `*.txt` / `*.pdf` / `*.epub` | ❌ | 语料本身，已被 `.gitignore` 忽略 |

`data/` 目录中的派生 JSON **会**提交——但它只包含统计、元数据与约 36 字以内的诗句摘录，不包含完整诗篇。

## 管线对文本格式的预期

管线不要求严格格式，但它是围绕西川编《海子诗全集》的排版特征设计的：

- 一首诗以**标题**开始，正文之后跟**日期**（如 `1984.4`、`1985.7.12`、`1988.6.8—10`）；
- 日期与下一篇标题可能因 PDF 提取合并到同一行（如 `1984.6新娘`），管线会据此切分；
- 编者注（`——编者注`）会被识别并跳过。

如果你的语料排版不同，切分效果可能下降——这是「尽力而为」的提取，偏差已在 README 中说明。
